# 🍟 30-Minute Hands-On Workshop: Building an AI Food Ordering Chatbot with Google A2UI

Welcome to the **Google A2UI (Agent-to-UI)** Hands-On Workshop! This 30–40 minute session is designed to teach attendees the foundational concepts of generative user interfaces using **Google's `@a2ui/react` SDK** and a **McDonald's AI Chatbot** use case.

---

## ⏱️ Workshop Schedule (35 Minutes Total)

| Time | Segment | What Attendees Learn & Do |
| :--- | :--- | :--- |
| **00 - 05m** | **The Problem** | Why traditional text chatbots fail for food ordering (typing tedious modifications vs rich interactive widgets). |
| **05 - 12m** | **A2UI Core Concepts** | The 3 Core Messages (`createSurface`, `updateComponents`, `updateDataModel`) + Two-Way Data Binding. |
| **12 - 25m** | **Hands-On Coding** | Interactive ordering flow in Chatbot + Live A2UI Protocol Inspector experiments. |
| **25 - 30m** | **Live Action Events** | How user clicks inside A2UI surfaces loop back to the Agent without page refreshes. |
| **30 - 35m** | **Q&A & Takeaways** | Cross-platform portability (React, Flutter, SwiftUI) and Security by Design. |

## 🚀 Quick Setup (2 Minutes)

### Step 1: Run the Frontend
```bash
cd client
npm install
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

> [!TIP]
> The app runs in **⚡ Local POC Mode** by default, allowing attendees to explore all A2UI features immediately without needing Python setup or API keys!

### Step 2: (Optional) Run the Live Python ADK Backend
```bash
cd server
bash run.sh
```
In the web header, toggle to **`🟢 Python ADK Backend`**.

## 🧪 3 Hands-On Coding Exercises for Attendees

### 🛠️ Exercise 1: Inspecting the 3 Core Messages (5 Mins)
1. In the chat input, type: `"Show me the menu"` (or click the **`🍔 Show Menu`** prompt chip).
2. Look at the **A2UI Live Inspector** on the right side:
   - **`createSurface`**: Sets up the surface ID and theme.
   - **`updateComponents`**: Hierarchical component tree (`Column` ➔ `Row` ➔ `Card` ➔ `Image` + `Button`).
   - **`updateDataModel`**: Injects Indian McDonald's meal data (`/meals`).

---

### 🛠️ Exercise 2: Two-Way Data Binding & Customizations (7 Mins)
1. In the chat, click **`🍟 Customize McSpicy Paneer`**.
2. Notice the inline customizer widget rendered in the chat bubble.
3. Toggle the **"🌶️ Piri Piri Spice Mix"** and **"🧀 Extra Cheese Slice"** checkboxes.
4. **Key Concept to Explain**: Notice how the local UI state updates instantly at 60 FPS without waiting for an LLM network roundtrip.

---

### 🛠️ Exercise 3: Live UI Event Dispatching (8 Mins)
1. Inside the customizer card, tap **`Add Customized Meal to Order 🛒`**.
2. Switch to the **`⚡ Actions`** tab in the Inspector.
3. Observe how `@a2ui/react` intercepted the click and emitted:
   ```json
   {
     "eventName": "submit_custom_meal",
     "context": {
       "mealName": "McSpicy Paneer Meal",
       "basePrice": 429.00
     }
   }
   ```
4. The Agent automatically receives this event and returns the next conversation turn: the **Kiosk Tray & GST Tax Breakdown**!
5. Tap **`Pay via UPI & Generate Invoice`** to watch the animated **Tax Invoice & Token #88** render with confetti celebration.

## 💡 Key A2UI Architectural Takeaways for Slides

1. **Security by Design**: The Agent never sends executable code or arbitrary HTML. It only emits declarative JSON referencing trusted native client components.
2. **Hybrid Conversational + Touch**: Users speak fuzzy intent ("McSpicy paneer with extra cheese and Thums up"), and the AI delivers an exact touch widget for one-tap confirmation.
3. **Framework Agnostic**: The exact same A2UI JSON stream generated by Gemini can be rendered by React, Angular, Flutter, iOS SwiftUI, and Android Jetpack Compose.
